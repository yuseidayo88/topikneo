# 動作確認チェックリスト

主要画面の遷移とクイズフローが想定どおり動くか確認するためのチェックリストです。

## 単語クイズ

- [ ] **開始〜完了**
  - 単語タブ → レベル選択 → レッスン一覧 → レッスン → 「クイズ開始」
  - 10問すべて回答し、全正解で結果画面 → 「クリア！」表示
  - 10問中1問以上不正解で結果画面 → 「もう一度挑戦しよう」表示
- [ ] **続きから**
  - クイズ開始後、3問目あたりでナビの×をタップ → 「クイズを中断しますか？」と表示され、レッスン画面へ戻る
  - 再度「クイズ開始」をタップ → 「続きから」バナーが表示され、4問目から再開されること
- [ ] **中断確認**
  - ナビの×タップで「本当に中断しますか？」（または「クイズを中断しますか？」）のダイアログが出ること
  - キャンセルでクイズ継続、中断するで戻ること
- [ ] **もう一度**
  - 結果画面で「もう一度」をタップ → 同じレッスンのクイズが最初から（1問目）始まること
  - クリア済みレッスンを開き「クイズ開始」→ 新規クイズとして1問目から始まること
- [ ] **レッスン一覧のドット**
  - 最後に受けたクイズの結果が、緑（正解）・赤（不正解）のドットで表示されること
  - 全問正解でクリアしたレッスンは緑の「クリア」バッジになること

## 復習・保存単語クイズ

- [ ] 今日の復習／保存した単語クイズで、ナビに×ボタンがあり、タップで中断確認ダイアログが出ること
- [ ] 進捗バー（グレートラック＋塗りつぶし）と「N / 総数」「正解: N」が単語クイズと同じスタイルで表示されること

## ハングルパズル

- [ ] 単語タブ → 「ハングルパズル」→ コース選択画面でスクロールできないこと
- [ ] コース選択 → プレイ画面でスクロールできないこと
- [ ] 10問終了後、結果画面が表示され「もう一度」「コース一覧へ」で遷移できること

## ホーム・レッスン一覧

- [ ] ホームの「レベル別進捗」に「X / Y」のみ表示されること（「レッスン」の文字はない）
- [ ] レッスン一覧で「進捗」ラベルと「X / Y レッスンクリア」・プログレスバーが表示されること
- [ ] ヒントに「緑=正解・赤=不正解は最後のクイズ結果」と表示されること

## 遷移の要所

- [ ] 結果画面「次のレッスンへ」→ **そのレベルのレッスン一覧**へ（単語タブトップではない）
- [ ] 結果画面「ホームへ」→ ホームタブへ
- [ ] ハングルパズル結果「コース一覧へ」→ パズルコース選択へ
- [ ] ハングルパズル結果「単語タブへ」→ 単語タブへ

## タブ復帰時のリセット

- [ ] **単語タブ**で `TOPIK1` など深い画面へ遷移 → 他タブへ移動 → 単語タブに戻ると、単語トップ画面が表示されること
- [ ] **文法タブ**で `TOPIK1` など深い画面へ遷移 → 他タブへ移動 → 文法タブに戻ると、文法トップ画面が表示されること
- [ ] 上記の操作で、不自然な横スライド（右から現れる遷移）が発生しないこと
- [ ] 単語/文法/ホームを途中までスクロールして他タブへ移動し、戻ったときに先頭位置から表示されること

## 初回ロード体験

- [ ] アプリ起動直後に単語タブを開いたとき、テスト用の暫定件数（例: TOPIK1が1件など）が表示されないこと
- [ ] 単語データ未取得時は `読み込み中` が表示され、取得完了後に正しい件数へ切り替わること
- [ ] 文法データ未取得時は `読み込み中` が表示され、取得完了後に正しい件数へ切り替わること
- [ ] 通信が不安定でも起動時プリロードの再試行で復帰できること（必要なら機内モードON/OFFで確認）

## オンボーディング

- [ ] 初回起動時（またはオンボーディング未完了時）にオンボーディングが表示されること
- [ ] 「使い方のヒント」ステップで、単語・ハングルパズルの簡単な説明が表示されること

## エラー・再試行

- [ ] 2級以上のレッスン一覧で単語取得に失敗した場合、「読み込みに失敗しました」と「再試行」ボタンが表示されること（ネットワークオフ時などで確認可能なら）

## 通知

- [ ] リマインダーを有効にしている場合、設定時刻に「1日1レッスンクリアで連続記録をキープ」などの通知が届くこと
