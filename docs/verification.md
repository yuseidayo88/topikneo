# 動作確認チェックリスト

## 文法オフライン（キャッシュ）

1. アプリを起動し、**文法タブ**を開いてデータを読み込む（レベル一覧が表示されるまで待つ）。
2. **機内モード**をオンにする。
3. アプリをバックグラウンドにしたあと再度開く、または文法タブを一度離れて戻る。
4. **確認**: 文法のレベル一覧・レッスン一覧がキャッシュで表示され、並び替えクイズも動作すること。

## Error Boundary・アクセシビリティ

- **文法クイズ**: 文法タブ → TOPIK 1級 → レッスン1 → クイズ開始 → 1問並び替え → 確認。クラッシュせず結果まで進むこと。
- **単語クイズ**: 単語タブ → 入門 → レッスン1 → クイズ開始 → 1問解答。同様に最後まで進むこと。
- **VoiceOver / TalkBack**: クイズ画面で「ヘッダー」「メイン」や問題の読み上げ順が自然か確認（任意）。

## E2E（Maestro）

- Maestro CLI をインストールしたうえで、シミュレータまたは実機でアプリを起動し、`maestro test .maestro/flows/` を実行。単語・文法の主要フローが通ること。
